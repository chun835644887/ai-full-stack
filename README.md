# ai-full-stack

一名前端工程师转型 AI 全栈开发的学习仓库：30 天学习路线 + 后续每个阶段的可运行项目。

## 内容

- [AI-full-stack-30-day-roadmap.md](./AI-full-stack-30-day-roadmap.md)：30 天学习路线，133 个可勾选任务，含官方文档与课程链接、每阶段动手练习与项目产出。

## 技术主线

TypeScript + Node.js + Next.js + OpenAI API + Vercel AI SDK

## 怎么用

1. 从文件的“环境准备（Day 0）”开始，逐项勾选任务。
2. 每个阶段完成一个可运行的小项目，最后一周完成一个毕业大作业。
3. 把每个阶段的代码和踩坑记录也提交到这个仓库，形成自己的作品集。

## 进度

- [ ] 第 1 周：LLM 基础与 API 上手（Day 1–7）
- [ ] 第 2 周：RAG 与工具调用（Day 8–14）
- [ ] 第 3 周：智能体与全栈整合（Day 15–21）
- [ ] 第 4 周：生产化与大作业（Day 22–30）
